# 🦕 方舟：生存飞升 (ASA) Web 版开服工具

## 简介
本工具是专为《方舟：生存飞升》（ARK: Survival Ascended） 打造的轻量化 Web 开服管理面板。项目基于 `Node.js` + `Express` + `Bootstrap` 开发，纯 Windows 环境适配，旨在让没有专业运维知识的新手也能通过可视化的网页界面一键部署、配置和管理服务器。

**最大的优势在于：程序打包后可直接运行（单文件 .exe），支持本地/远程服务器部署，无需提前安装 Node.js 环境，可直接发布供玩家使用。**

## 核心特性 (Core Features)

*   **可视化操作**：全 Web 界面配置，涵盖了服务器、玩家、生物、建筑、世界、规则等各项核心参数，界面布局与官方游戏 UI 高度一致，并附带详细说明。彻底告别修改繁琐 `.ini` 配置文件的痛苦，零基础快速上手。
*   **一键下载更新**：内置一键下载安装/更新服务端功能，免去繁琐的 SteamCMD 手动操作。
*   **一键启停**：支持服务器一键启动、停止，并带有防止误触的二次确认，服务器状态（运行中/已停止）在网页端实时同步。
*   **实时监控**：仪表盘直观显示服务器当前运行状态、CPU 占用、内存占用、实时在线人数以及控制台日志（需配合 RCON）。
*   **日志管理**：网页端实时刷新服务器运行终端日志，支持日志内容的清空。
*   **存档备份**：提供一键存档，以及一键备份与恢复功能，有效防止坏档或数据丢失。
*   **配置持久化**：用户在网页端的配置更改会自动保存至本地 `config.json` 文件，重启工具或服务器后配置不丢失。
*   **响应式界面**：基于 Bootstrap 开发的前端界面，完美适配 PC、平板、手机端浏览器，方便服主随时随地进行远程管理。
*   **免环境安装**：最终产物打包为单文件 `.exe` 可执行程序，用户只需双击运行即可开启 Web 服务，无需提前配置 Node.js 运行环境。

## 快速开始 (运行 EXE)

推荐直接使用我们打包好的 EXE 可执行文件，双击即可运行。

1. **下载与运行**：
   - 将程序文件夹解压到任意位置（建议路径中不要包含中文）。
   - 双击运行文件夹中的 `ARK-ASA-ServerTool.exe`。
   - 首次运行如果遇到杀毒软件（如 Windows Defender、360 等）误报拦截，请将其**添加至信任区/白名单**。

2. **访问面板**：
   - 程序运行后，会自动弹出一个黑色的控制台窗口。
   - 控制台中会显示面板的访问地址（通常是 `http://localhost:3000` 或其他端口）。
   - 在浏览器中打开该地址，即可进入可视化的管理面板。

*(注：如果你不想使用 EXE，或者你的网络环境无法下载 EXE 运行所需的依赖，你也可以选择在安装 Node.js 后，通过源码目录下的 `install.bat` 和 `start.bat` 来运行面板。)*

## 面板使用指南

### 1. 安装与更新服务端
- **一键下载安装**：首次使用时，面板右侧的“服务器控制”区域会显示“服务端状态：未安装”。点击 **“一键下载安装”** 按钮，工具会自动下载 SteamCMD 并拉取最新的 ASA 服务端文件。由于文件较大（约几十GB），请耐心等待控制台提示下载完成。
- **检查更新**：当服务端已经安装后，该按钮会自动变为 **“检查更新”**。你可以随时点击它来更新游戏服务端至最新版本。

### 2. 基础设置与参数配置
- 在面板左侧的“服务器”、“玩家”、“生物”、“建筑”、“世界”、“规则”等 Tab 页中按需调整参数。
- **参数说明**：每个参数下方都带有详细的中文说明，并明确指出了数值调大或调小对游戏的影响（例如：恐龙承受伤害系数，数值越小恐龙越抗揍）。
- **保存配置**：配置修改完毕后，点击左侧底部的 **“保存所有配置”**，或者直接点击右侧的 **“启动服务器”**，修改就会自动写入到游戏的 `Game.ini` 和 `GameUserSettings.ini` 配置文件中。

### 3. 启动与停止服务器
- 点击右侧的 **“启动服务器”** 按钮即可开服。启动过程需要一定时间，请关注下方控制台输出的日志。
- 如需停止，点击 **“停止服务器”**，系统会弹出二次确认框，确认后即可安全关闭服务端进程。

### 4. 存档备份与恢复
- **立即存档**：在右侧控制面板点击 **“立即存档”** 按钮，可立即对当前世界进行存档（注：此功能依赖 RCON，如果未开启 RCON，请在游戏内使用管理员命令 `cheat SaveWorld`）。
- **一键备份**：点击 **“一键备份”** 按钮，工具会将服务端的 `Saved` 目录打包成 `.zip` 压缩文件，并存放在程序同级的 `backups` 文件夹中。
- **恢复存档**：如果遇到坏档，点击 **“恢复存档”** 按钮。在弹出的列表中选择你想要恢复的备份点并确认。系统会自动将当前的损坏存档重命名备份，然后将所选的压缩包解压替换，确保数据安全。**强烈建议在恢复存档前先停止服务器！**

## 常见问题 (FAQ)

- **Q: 为什么获取不到实时在线人数？**
  A: 实时在线人数功能依赖于 RCON 协议。请确保你在“服务器”配置页中开启了 RCON，并设置了正确的 RCON 端口和密码。目前版本仅作展示，如果需要真实数据请确保 RCON 能够正常连接。

- **Q: 服务器启动后，在游戏里搜不到？**
  A: 请检查你的路由器（如果是家用电脑开服）和 Windows 防火墙是否已放行对应的 UDP 端口（默认游戏端口 7777，查询端口 27015）。如果是云服务器，请在控制台的安全组中开放这些 UDP 端口。

- **Q: 面板修改了参数，但在游戏里没生效？**
  A: 请确保你在面板中修改完参数后，点击了“启动服务器”（或先停止再启动），配置才会被写入到 INI 文件中生效。如果服务器正在运行中，直接修改面板参数是不会立即生效的，必须重启服务器。

- **Q: 为什么 EXE 运行时提示 "Cannot mkdir in a snapshot" 错误？**
  A: 这是旧版本的 Bug，当前最新版本已经修复。如果仍有发生，请确保你使用的是最新编译的 EXE，并且将其放在了一个有读写权限的普通文件夹中。

## 工具文件结构 (Directory Structure)

项目在开发与打包前后的整体结构规划如下：

```text
ARK-ASA-Web开服工具/
├── server/                # 后端核心代码
│   ├── server.js          # 主服务程序 (Express 路由, 进程管理, API接口)
│   ├── config.json        # 配置自动保存文件 (持久化存储用户面板设置)
│   └── node_modules/      # 依赖包（打包 .exe 后将自动集成在内）
├── public/                # 前端静态资源
│   ├── index.html         # Web 管理面板主界面
│   ├── css/               # 样式文件 (包含 Bootstrap 定制样式)
│   └── js/                # 前端交互脚本 (AJAX/WebSocket 通信逻辑)
├── start.bat              # 开发/免安装环境下的快速启动脚本
├── install.bat            # 开发/免安装环境下的依赖安装脚本
├── README.md              # 面板使用说明与文档
└── build/                 # (最终构建产物) 存放打包后的 .exe 文件
    └── ARK-ASA-ServerTool.exe
```

## 技术栈
*   **后端**: Node.js + Express (提供 API 接口与静态文件服务)
*   **前端**: HTML5 + CSS3 + 原生 JavaScript + Bootstrap (响应式 UI 组件库)
*   **打包工具**: `pkg`，用于将 Node.js 项目打包为独立的 Windows `.exe` 文件。
*   **系统交互**: 使用 Node.js `child_process` 模块进行 ASA 进程控制与状态读取。
